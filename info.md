## English

Control your Klafs sauna directly from Home Assistant!

### Features

- 🌡️ **Temperature Control** - Set your sauna temperature like a thermostat
- 🔥 **Remote Start** - Start your sauna before arriving home
- 💧 **SANARIUM Mode** - Switch between classic Sauna and SANARIUM with humidity control
- 📊 **Real-time Monitoring** - Current temperature, humidity and status
- 🏠 **Multi-sauna Support** - Manage multiple saunas from a single account
- 🔐 **Individual PIN Codes** - Each sauna can have its own security PIN
- ⏰ **Time Scheduling** - Schedule your sauna start time
- 🤖 **Automations** - Create custom scenarios

### Installation

#### Via HACS (Recommended)

1. Open HACS in Home Assistant
2. Click on "Integrations"
3. Click the three dots in the top right
4. Select "Custom repositories"
5. Add URL: `https://github.com/richardthibault/klafs-homeassistant`
6. Category: "Integration"
7. Search for "Klafs Sauna" and install
8. Restart Home Assistant

#### Configuration

1. Go to **Settings** > **Devices & Services**
2. Click **+ Add Integration**
3. Search for **"Klafs Sauna"**
4. Follow the 3 steps:
   - Enter your Klafs Sauna App credentials
   - Select your saunas
   - Configure PIN codes (optional)

### Requirements

- Home Assistant 2023.1.0 or higher
- Klafs Sauna App account
- Klafs sauna with Wi-Fi module and "KLAFS Sauna App" option

## Deutsch

Steuern Sie Ihre Klafs-Sauna direkt von Home Assistant aus!

### Funktionen

- 🌡️ **Temperaturregelung** - Stellen Sie die Saunatemperatur wie ein Thermostat ein
- 🔥 **Fernstart** - Starten Sie Ihre Sauna vor der Heimkehr
- 💧 **SANARIUM-Modus** - Wechseln Sie zwischen klassischer Sauna und SANARIUM mit Feuchtigkeitskontrolle
- 📊 **Echtzeit-Überwachung** - Aktuelle Temperatur, Luftfeuchtigkeit und Status
- 🏠 **Multi-Sauna-Unterstützung** - Verwalten Sie mehrere Saunen von einem Konto aus
- 🔐 **Individuelle PIN-Codes** - Jede Sauna kann ihren eigenen Sicherheits-PIN haben
- ⏰ **Zeitplanung** - Planen Sie die Startzeit Ihrer Sauna
- 🤖 **Automatisierungen** - Erstellen Sie benutzerdefinierte Szenarien

### Installation

#### Über HACS (Empfohlen)

1. Öffnen Sie HACS in Home Assistant
2. Klicken Sie auf "Integrationen"
3. Klicken Sie auf die drei Punkte oben rechts
4. Wählen Sie "Benutzerdefinierte Repositories"
5. URL hinzufügen: `https://github.com/richardthibault/klafs-homeassistant`
6. Kategorie: "Integration"
7. Suchen Sie nach "Klafs Sauna" und installieren Sie
8. Starten Sie Home Assistant neu

#### Konfiguration

1. Gehen Sie zu **Einstellungen** > **Geräte & Dienste**
2. Klicken Sie auf **+ Integration hinzufügen**
3. Suchen Sie nach **"Klafs Sauna"**
4. Folgen Sie den 3 Schritten:
   - Geben Sie Ihre Klafs Sauna App-Anmeldedaten ein
   - Wählen Sie Ihre Saunen aus
   - Konfigurieren Sie PIN-Codes (optional)

### Voraussetzungen

- Home Assistant 2023.1.0 oder höher
- Klafs Sauna App-Konto
- Klafs-Sauna mit WLAN-Modul und "KLAFS Sauna App"-Option
