## Navigation

Each documentation file includes a language navigation header at the top:

```markdown
**Read in other languages:** [English](../en/FILE.md) | [Français](../../FILE.md) | [Deutsch](../de/FILE.md) | [Español](../es/FILE.md)
```

This allows easy switching between language versions.

## Contributing Translations

To add a new language or improve existing translations:

1. Create a new directory under `docs/` with the language code (e.g., `docs/it/` for Italian)
2. Translate the files or create summary versions
3. Add the language navigation header to all files
4. Update this README with the new language
