# Hoja de Ruta Futura

**Leer en otros idiomas:** [English](FUTURELOG.md) | [Français](FUTURELOG.fr.md) | [Deutsch](FUTURELOG.de.md) | **Español**

Este documento describe las características y mejoras planificadas para futuras versiones de la integración Klafs Sauna para Home Assistant.

Para la hoja de ruta completa, consulte la [versión en inglés](FUTURELOG.md).

---

## Versiones Planificadas

### [1.2.0] - Próximamente
- Soporte para múltiples cuentas Klafs
- Entidad Number para controlar humedad mediante slider
- Entidad Select para elegir modo (Sauna/SANARIUM/IR)
- Presets de temperatura (Finlandés, Suave, Intenso, etc.)
- Historial de sesiones de sauna

### [1.1.0] - Próximamente
- Soporte completo del modo Infrarrojo
- Sensor de tiempo de baño restante
- Servicio para establecer duración del baño
- Notificaciones push cuando el sauna está listo
- Gráficos de consumo energético (si está disponible vía API)

### [2.0.0] - Largo Plazo
- Soporte de API local si Klafs la hace disponible
- Reducción de latencia con WebSocket si está disponible
- Soporte de sauna multi-zona
- Integración con sistemas de ventilación
- Soporte de iluminación y aromaterapia si está disponible
