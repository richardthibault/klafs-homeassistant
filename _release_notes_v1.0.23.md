## 🇬🇧 English

### Changed
- **Optimized icon layout**: Removed bench to enlarge heater and stones
- Icons now more visible and clearer
- Heater and stones centered and enlarged for better visibility

### What's New
This version improves the custom icon design by removing the bench element and enlarging the key components (heater and heating stones). The icons are now clearer and easier to distinguish at a glance.

### Upgrade Instructions
**Via HACS (Recommended)**
1. Open HACS → Integrations
2. Find "Klafs Sauna" → Update
3. Restart Home Assistant
4. Clear browser cache (Ctrl+F5) to see new icons

### Geändert
- **Optimiertes Icon-Layout**: Bank entfernt, um Heizung und Steine zu vergrößern
- Symbole jetzt sichtbarer und klarer

## 🇪🇸 Español

### Cambiado
- **Diseño de iconos optimizado**: Banco eliminado para agrandar calentador y piedras
- Iconos ahora más visibles y claros
- Calentador y piedras centrados y agrandados para mejor visibilidad

### Novedades
Esta versión mejora el diseño de los iconos personalizados eliminando el elemento banco y agrandando los componentes clave (calentador y piedras calientes). Los iconos ahora son más claros y más fáciles de distinguir de un vistazo.

### Instrucciones de actualización
**Via HACS (Recomendado)**
1. Abrir HACS → Integraciones
2. Buscar "Klafs Sauna" → Actualizar
3. Reiniciar Home Assistant
4. Limpiar caché del navegador (Ctrl+F5) para ver los nuevos iconos
