# Future Roadmap

**Read in other languages:** **English** | [Français](FUTURELOG.fr.md) | [Deutsch](FUTURELOG.de.md) | [Español](FUTURELOG.es.md)

This document outlines planned features and improvements for future versions of the Klafs Sauna Home Assistant integration.

---

## [Unreleased]

### Planned for Future Versions

#### [1.2.0] - Coming Soon
- Support for multiple Klafs accounts
- Number entity to control humidity via slider
- Select entity to choose mode (Sauna/SANARIUM/IR)
- Temperature presets (Finnish, Gentle, Intense, etc.)
- Sauna session history

#### [1.1.0] - Coming Soon
- Full Infrared mode support
- Remaining bath time sensor
- Service to set bath duration
- Push notifications when sauna is ready
- Energy consumption graphs (if available via API)

#### [2.0.0] - Long Term
- Local API support if Klafs makes it available
- Latency reduction with WebSocket if available
- Multi-zone sauna support
- Integration with ventilation systems
- Lighting and aromatherapy support if available

## Ideas Under Discussion

These features are being considered but not yet scheduled:

### Smart Automation
- Calendar integration for automatic scheduling
- Presence detection for automatic start
- Smart energy saving mode based on usage patterns
- Integration with weather forecasts (outdoor temperature consideration)

### Analytics & Monitoring
- Usage statistics and reports
- Session duration tracking
- Energy consumption analysis (if API provides data)
- Temperature/humidity history graphs

### User Experience
- Multiple user profile support
- Voice assistant improvements (Google Assistant, Alexa, Siri)
- Mobile app notifications with rich actions
- Quick action widgets

### Advanced Features
- Air quality sensor integration
- Integration with smart home scenes
- Geofencing for automatic preheating
- Machine learning for optimal preheating times

### Hardware Integration
- Support for additional Klafs accessories
- Integration with smart lighting systems
- Aromatherapy dispenser control
- Music/audio system integration

1. **Check existing issues**: https://github.com/richardthibault/klafs-homeassistant/issues
2. **Create a feature request**: Use the feature request template
3. **Discuss on forum**: https://community.home-assistant.io
4. **Vote on existing requests**: Add 👍 to issues you want

---

## Priority Criteria

Features are prioritized based on:

1. **User demand**: Number of requests and votes
2. **API availability**: Whether Klafs API supports it
3. **Complexity**: Development effort required
4. **Compatibility**: Home Assistant best practices
5. **Maintenance**: Long-term support considerations
