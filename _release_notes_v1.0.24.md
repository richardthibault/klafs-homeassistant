## 🇬🇧 English

### Changed
- **Enlarged icon display**: Adjusted viewBox to make icons appear larger
- Icons now match the size of other Home Assistant icons
- Better visibility in entity cards and dashboards

### What's New
This version fixes the icon size issue where Klafs icons appeared smaller than other Home Assistant icons. The viewBox has been adjusted to zoom in on the icon content, making them the same size as standard icons.

### Upgrade Instructions
**Via HACS (Recommended)**
1. Open HACS → Integrations
2. Find "Klafs Sauna" → Update
3. Restart Home Assistant
4. Clear browser cache (Ctrl+F5) to see enlarged icons

## 🇩🇪 Deutsch

### Geändert
- **Vergrößerte Icon-Anzeige**: ViewBox angepasst, um Symbole größer erscheinen zu lassen
- Symbole entsprechen jetzt der Größe anderer Home Assistant Symbole
- Bessere Sichtbarkeit in Entitätskarten und Dashboards

### Was ist neu
Diese Version behebt das Problem der Symbolgröße, bei dem Klafs-Symbole kleiner als andere Home Assistant-Symbole erschienen. Die ViewBox wurde angepasst, um auf den Symbolinhalt zu zoomen und sie auf die gleiche Größe wie Standardsymbole zu bringen.

### Aktualisierungsanleitung
**Via HACS (Empfohlen)**
1. HACS öffnen → Integrationen
2. "Klafs Sauna" finden → Aktualisieren
3. Home Assistant neu starten
4. Browser-Cache leeren (Strg+F5), um vergrößerte Symbole zu sehen

## 🇪🇸 Español

### Cambiado
- **Visualización de iconos ampliada**: ViewBox ajustado para hacer los iconos más grandes
- Los iconos ahora coinciden con el tamaño de otros iconos de Home Assistant
- Mejor visibilidad en tarjetas de entidades y paneles

### Novedades
Esta versión corrige el problema de tamaño de iconos donde los iconos de Klafs aparecían más pequeños que otros iconos de Home Assistant. El viewBox se ha ajustado para hacer zoom en el contenido del icono, haciéndolos del mismo tamaño que los iconos estándar.

### Instrucciones de actualización
**Via HACS (Recomendado)**
1. Abrir HACS → Integraciones
2. Buscar "Klafs Sauna" → Actualizar
3. Reiniciar Home Assistant
4. Limpiar caché del navegador (Ctrl+F5) para ver los iconos ampliados
